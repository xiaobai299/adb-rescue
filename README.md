# 安卓手机救援控制工具（ADB）v2.0.5

一款面向**屏幕损坏、无法触控但系统仍可正常运行**的 Android 手机的桌面救援工具。通过 USB 数据线与电脑相连，在手机上已开启并授权 USB 调试的前提下，实现投屏镜像、鼠标/键盘反向控制、数据导出、应用管理、截图录屏、日志抓取与系统运维等操作。

**v2.0 核心升级**：完整利用手机 **root 权限** —— 全量应用备份（含 /data/data 内部数据）、聊天/系统数据直接导出、root 文件浏览、系统级操控提速；并进一步优化投屏与控制流畅度（低延迟模式、TCP/IP 通道、默认高码率）。

---

## 1. 功能总览

| 模块 | 核心能力 |
|------|----------|
| 设备检测 | 自动识别已连接设备，显示型号、分辨率、电量、Android 版本、连接状态；**顶部直接显示 ROOT 状态徽标**；未授权时给出具体授权引导 |
| 实时投屏 | 内置 `screencap` 帧引擎（3~10 FPS）+ **scrcpy 高帧率引擎**（可跑满 120Hz），支持低延迟模式、TCP/IP 通道、音频同步 |
| 反向控制 | 鼠标模拟点击、长按、滑动、手势；键盘输入；返回/Home/多任务/音量/电源等按键；黑屏/锁屏时唤醒 |
| 数据导出 | 浏览并导出照片、视频、文档；导出联系人、短信、通话记录；**root 模式下可浏览 /data 等私有目录** |
| 应用管理 | 安装/卸载/备份 APK、启动/停止应用；**root 设备一键完整备份（APK + 内部数据 + 外置数据）** |
| Root 高级 | root 状态检测（Magisk/SuperSU/adb root）、一键提速（关动画/GPU/常亮）、聊天应用数据导出（微信/QQ/WhatsApp/Telegram…）、短信/通话/通讯录数据库直读导出、root 文件浏览器、系统应用冻结/卸载/恢复 |
| 运维工具 | 截图、录屏、logcat、shell 命令（**支持以 root 执行**）、重启/Recovery/Fastboot/关机、电池/存储/内存体检 |

## 2. 依赖

- **Python 3.9 或更高版本，且必须包含 tkinter**
- **Pillow**：用于解码和缩放投屏画面
- **ADB**：程序自带于 `tools/adb.exe`，无需另行安装
- **scrcpy**：随包自带于 `tools/scrcpy/`，用于高帧率独立窗口
- **root（可选但推荐）**：Magisk / SuperSU 等，用于完整备份、私有数据导出、系统级操作

> ⚠️ 部分精简版 Python（例如各类绿色/嵌入式发行版）**不含 tkinter**，用它启动会在
> `import tkinter` 时直接崩溃。`启动.bat` 会自动探测并跳过这类解释器；
> 若全部候选都不可用，请安装 [python.org 官方版本](https://www.python.org/downloads/)，
> 安装时勾选 `Add python.exe to PATH` 与 `tcl/tk and IDLE`。

## 3. 启动方式

**免安装绿色版（推荐，无需 Python）**：解压 `adb-rescue-v2.0-win64.zip`，
双击其中的：

```text
ADB救援工具.exe
```

exe 同目录的 `tools/`（自带 adb 与 scrcpy）与 `_internal/`（运行库）请保持完整，
不要单独移动 exe。命令行附加 `--selftest` 可运行环境自检。

**源码方式**：Windows 用户直接双击：

```text
启动.bat
```

脚本会依次完成：选择一个**带 tkinter** 的 Python → 检查并按需安装 Pillow →
检查 adb（优先使用自带的 `tools/adb.exe`）→ 启动图形界面。

命令行方式（需自行确保解释器带 tkinter 且已装 Pillow）：

```bash
python main.py
```

## 5. Root 高级页（v2.0 新增）

- **Root 状态卡**：一键检测 su 方式（Magisk/SuperSU/adb root）、Magisk 版本、SELinux 状态、/data 可读性；支持 `adb root`（userdebug 固件）与打开 Magisk 应用。
- **操控提速**：关闭系统动画、强制 GPU 渲染、root 屏幕常亮、临时切换 SELinux（重启恢复）。
- **应用完整备份**：任意包名 → 一键导出 APK（root 直读 /data/app）+ `/data/data/<包名>` 内部数据（tar.gz 流式）+ 外置数据。聊天记录、登录态、数据库全部包含。
- **聊天与系统数据**：微信/QQ/WhatsApp/Telegram/钉钉/企业微信/支付宝数据目录一键打包；短信、通话记录、通讯录**直接读取系统数据库**导出 CSV —— 不再受 Android 4.4+ 的 ContentProvider 授权限制。
- **Root 文件浏览器**：以 root 浏览任意目录（/data、/data/data 等），支持整目录 tar.gz 导出与选中文件下载。
- **系统应用管理**：冻结/解冻、仅当前用户卸载（`pm uninstall -k --user 0`，可恢复）、恢复系统应用。

## 6. 流畅度优化（v2.0）

1. **一键流畅投屏**（v2.0.2 引入）：引擎选「scrcpy 高帧率（推荐）」时点主按钮
   「开始投屏」，即自动套用与 **直接双击 scrcpy.exe 完全一致**的稳妥参数 ——
   **720p / 60 帧 / 8M 码率 / 默认显示缓冲 / USB 直连 / scrcpy 窗口直接控制**。
   直接运行不卡；未找到 scrcpy 时自动回退内置引擎（3~10 FPS）。
2. **引擎互斥**（v2.0.2）：内置引擎与 scrcpy **不可同时运行**——同时跑会争抢 USB
   带宽导致画面卡顿。启动任一引擎会自动停止另一个。
3. **scrcpy 自动识别**：除随包自带的 `tools/scrcpy` 外，还会自动扫描各盘符根目录下的
   `scrcpy*` 文件夹（例如 `D:\scrcpy-win64-v4.1\scrcpy.exe`），无需手动配置。
4. **输出排空**（v2.0.2）：后台持续读取 scrcpy 日志，避免管道写满阻塞整个视频管线。
5. **默认 8M 码率**：与直接运行 scrcpy 的默认一致（v2.0 曾设为 12M，已回退）。
6. **低延迟模式**（可选）：`--video-buffer=0` + baseline 编码。注意 0 缓冲会取消
   抖动补偿，稍有波动画面反而一顿一顿，USB 直连场景**默认请保持关闭**。
7. **无线 TCP/IP**（可选）：`--tcpip` 在 scrcpy 4.x 中会把设备**重连到 Wi-Fi TCP/IP**，
   仅适合无线连接场景；USB 直连时它比默认通道慢。
8. **音频同步**（可选）：把手机声音转发到电脑（需 scrcpy 窗口直接控制）。
9. **内置引擎**：旋转、缩放、最大宽度限制、画质档位，适合低配环境兜底。
10. **输入不冻结界面**（v2.0.1）：点击/滑动/按键全部投递到**后台串行输入队列**执行，
    界面不再因每次 adb 子进程等待而冻结；连续操作按顺序送达设备。

## 7. 分层架构

```text
ui 界面层 → core 核心层 → adb 可执行文件
├─ ui.panel_screen / panel_files / panel_apps / panel_ops / panel_root
├─ core.adb       —— 唯一直接调用 adb 的层（定位、执行、设备枚举、信息采集）
├─ core.screen    —— 内置帧引擎 + scrcpy 外部引擎
├─ core.inputctl  —— 输入控制（触摸/按键/文本/唤醒保活）
├─ core.files     —— 文件浏览与导出（支持 root 回退）
├─ core.ops       —— 应用管理、截图录屏、logcat、电源
└─ core.root      —— root 层：su 检测、root shell、tar 流式导出、
                     全量备份、数据库直读、系统级操作
```

## 8. 使用建议（Root 版）

1. **连接与授权**：开发者选项中开启 USB 调试；连接电脑后确认「允许 USB 调试？」弹窗。
2. **Root 授权**：首次使用 root 功能前，在 Magisk → 设置中确认已授予 **Shell 超级用户** 权限；
   首次 root 命令会在手机端弹出授权请求（屏幕损坏时建议提前用 OTG 鼠标完成授权）。
3. **优先投屏**：需要顺畅操控时保持引擎为「scrcpy 高帧率（推荐）」，点「开始投屏」最稳。
4. **解锁进系统（屏幕损坏时）**：
   - **一键解锁**：在「键盘输入」框输入锁屏密码，点投屏页的「一键解锁」按钮——
     自动完成 唤醒 → 唤出密码面板（上滑）→ 输入 → 回车提交 → 验证，
     兼容密码面板常驻与停在时钟页两类 ROM；解锁成功后密码框自动清空。
   - **PIN / 数字密码（手动）**：投屏后用鼠标点一下密码框，在「键盘输入」框输入密码点发送，
     再点「回车」键提交；若数字键盘不接受文本，直接逐个点画面上的数字键即可。
   - **字母数字密码**：同上（ASCII 字符可直接发送；特殊符号建议点屏幕上的键盘）。
   - **图案锁**：在投屏画面上**按住鼠标慢速沿着图案连线拖动**——工具会按
     `motionevent DOWN/MOVE/UP` 发送单次连续手势（v2.0.3），图案可正常识别。
   - 本工具只帮你输入**你自己知道的密码**，不做暴力破解或绕过锁屏。
5. **救援第一优先**：先做「应用完整备份」与「聊天数据导出」，再执行任何卸载/清数据操作。
   （root 状态下即使锁屏，也能直接导出短信/通讯录/微信等全部数据。）
6. **中文输入**：原生 `input text` 仅支持 ASCII；中文需设备安装并启用 **ADBKeyboard** 输入法。

## 8b. 没开 USB 调试 / 没 root / 屏幕坏了怎么办

本工具的一切功能依赖「USB 调试」（adb 通道），没开调试时工具无法接管。
工具顶部提供了 **「没开USB调试?」** 帮助与 **「MTP 存储」** 一键入口：

- **MTP 文件传输（首选，无需 adb / root）**：USB 线直连电脑，满足两个条件即可像
  U 盘一样拷照片/视频/文档：① 锁屏为滑动锁/无密码（设了 PIN/图案会拦截 MTP，
  Android 10+ 必须先解锁）；② USB 模式为「传输文件 (MTP)」（屏幕坏无法切换时
  只能寄望出厂默认模式）。连上后点「MTP 存储」在『此电脑』里找到手机图标。
- **云同步**：若之前开过 Google 相册 / 厂商云 / 微信电脑版备份，直接从电脑取回。
- **换屏维修（保数据正道）**：换屏后数据原样保留，届时开启 USB 调试授权本工具即可接管。
- ⚠️ 不要因屏幕坏就恢复出厂 / 盲目刷机，会永久删除数据。

## 9. 合规与风险提示

- **仅面向已授权 USB 调试的合法设备**，不会也不包含绕过锁屏密码、图案、指纹或任何安全机制的功能。
- root 功能以设备所有者的 root 权限访问数据，请确保你对目标设备拥有合法所有权或已获授权。
- **破坏性操作**（卸载、清除数据、重启、Recovery、Fastboot、关机、冻结系统应用）会强制二次确认。
- SELinux 宽容、动画关闭等为临时调整，重启手机后自动恢复；恢复出厂设置不可用。

## 10. 故障排查速查

| 现象 | 原因与处理 |
|------|------------|
| 双击后窗口一闪而过 / 报 `No module named 'tkinter'` | 当前 Python 不含 tkinter，换用官方 Python 或生成项目内 `.venv`（见第 3 节）|
| 状态显示「未授权 USB 调试」 | 手机端必须点『允许』；屏幕损坏时用 OTG 鼠标点按，或用 Type-C 转接外接显示器后再操作 |
| Root 状态显示「未获取」 | 确认已装 Magisk/SuperSU 且授予 Shell 超级用户权限；userdebug 固件可执行『adb root』 |
| 完整备份提示需要 root | 该功能依赖 root；未 root 时请改用『导出应用外置数据』或 adb backup |
| 短信/通讯录导出失败 | 先尝试常规通道；root 通道直接读系统数据库，若仍失败可在 Root 文件浏览器中手动定位数据库目录 |
| 投屏画面卡顿 | 降低帧率/画质、限制最大宽度；或改用 scrcpy + 低延迟 + TCP/IP |
| 操控（点击/滑动）卡顿 | 输入命令已在后台队列执行（界面不再冻结）；若仍觉得延迟高，请改用 scrcpy 并勾选『scrcpy 窗口直接控制』（设备端本地注入，延迟最低），或把内置引擎画质调到『流畅』档 |
| 中文发送失败 | 安装 ADBKeyboard 并在系统输入法设置中启用 |
